# 울림 (Ullim)

무료로 공개된 음장 기법을 모아 만든 심플한 음악 플레이어. 윈도우와 안드로이드가 **같은 화면 · 같은 음장 엔진**을 씁니다.
곡에 맞는 **가사**를 인터넷에서 찾아 띄워 주고, 사용자들이 고른 가사가 **모두의 앱에 함께 반영**됩니다.

## 내려받기 — [최신 릴리스](https://github.com/omokdie/ullim/releases/latest)

| 기기 | 파일 |
|---|---|
| 윈도우 10/11 (64비트) | `Ullim-Setup-<버전>.exe` — 실행하면 설치 · 시작 메뉴/바탕 화면 바로 가기 · 제어판에서 제거 |
| 안드로이드 7.0 이상 | `Ullim-<버전>.apk` — 이전 버전 위에 덮어 설치하면 재생목록 · 설정이 그대로 남아요 |

윈도우에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**. (코드 서명 인증서가 없는 새 프로그램이라 처음 한 번 뜰 수 있어요)

## 가사 — 함께 고쳐 가는 가사

1. 곡이 바뀌면 순서대로 찾습니다: **내가 고른 가사** → 음악 파일 속 가사 · 같은 이름의 `.lrc` → **다른 사용자들이 고른 가사** → [LRCLIB](https://lrclib.net) 자동 검색 (제목 · 가수 · 앨범 · 길이)
2. 가사가 없거나 엉뚱하면 가사 화면에서 **직접 검색** 또는 **틀린 가사 제보** → 맞는 가사를 누르면 바로 그 곡의 가사로 정해지고, **의견이 자동으로 올라가** 다른 사용자들에게도 그 가사가 나옵니다. ("가사가 없는 곡이에요", "틀렸다고만 알리기"도 같은 방식)
3. 로그인 · 계정이 필요 없습니다. 설정 → 가사 → **내가 고른 가사를 다른 사용자와 나누기**로 끌 수 있어요.

```
앱 ──(익명 의견)──▶ ntfy.sh 메시지함 ──(30분마다)──▶ GitHub Actions ──▶ lyrics/overrides.json ──(2시간마다)──▶ 모든 앱
                      (12시간 보관)                  확인 · 투표 · 기록         (공용 가사 목록)
```

- **보내는 정보**: 곡 제목 · 가수 · 길이, 틀린/맞는 가사의 LRCLIB 번호, 앱 버전, 앱이 처음 만든 무작위 번호(한 사람 한 표용 — 공용 목록에는 해시로만 남음). 인터넷이 끊겨 있으면 앱에 쌓아 두었다가 다음에 보냅니다.
- **정하는 방법**: 한 사람(앱)은 한 곡에 한 표. 후보 점수 = "맞다" 표 − "틀리다" 표, 가장 높은 후보를 씁니다(동점이면 지금 가사 유지). "틀리다"가 더 많은 번호는 자동 검색에서 빠집니다.
- **엉뚱한 의견 막기**: 고른 가사가 LRCLIB 에 실제로 있어야 하고, 제목 · 가수가 비슷하거나 한쪽이 비슷하면서 곡 길이가 3초 안으로 같아야 바로 반영됩니다. 아니면 `needs-review` 이슈가 자동으로 열리고, 관리자가 `lyrics-approved` 라벨을 붙이면 반영돼요.
- GitHub 계정이 있다면 [이슈 양식](https://github.com/omokdie/ullim/issues/new?template=lyrics.yml)으로도 제보할 수 있습니다.
- 관리 방법은 [`lyrics/README.md`](lyrics/README.md) 참고.

## 음장 효과 (40종 + 10밴드 EQ)

- **공간 · 입체**: 스테레오 와이드, 3D 서라운드, 가상 스피커(HRTF), 8D 회전, 하스 입체감, 헤드폰 크로스피드(bs2b)
- **잔향 · 에코**: 리버브(Freeverb), 공간 시뮬레이션(콘서트홀·대성당 등 7종, 컨볼루션), 에코·딜레이(핑퐁)
- **음색 · 저음**: 베이스 부스트, 가상 저음, 초저음 생성, 트레블, 라우드니스, 크리스탈라이저, 익사이터, 진공관 웜
- **음량 · 다이내믹**: 컴프레서, 야간 모드, 볼륨 평준화, 리미터
- **보컬**: 보컬 제거(노래방), 보컬 강조
- **변조**: 코러스, 플랜저, 페이저, 트레몰로, 비브라토, 오토 팬, 로터리 스피커
- **속도 · 키**: 재생 속도(음정 유지), 키 조절(±12 반음)
- **특수 효과**: 라디오·전화, 수중, 로파이·비트크러셔, LP 레코드, 오버드라이브
- **채널**: 좌우 밸런스, 모노, 좌우 바꾸기

사용한 공개 기법: Freeverb(Jezar, 퍼블릭 도메인), bs2b 크로스피드 공식(MIT), RBJ Audio EQ Cookbook 필터, 브라우저 엔진 내장 HRTF, 상관관계 정렬 피치 시프트, 가상 저음(비선형 배음), 옥타브 분주 초저음, 샘플 차분 크리스탈라이저. 코드는 모두 새로 작성했습니다.

## 구조

```
web/                화면 + 음장 엔진 (두 플랫폼 공통)
  index.html, css/app.css
  js/app.js         재생 로직 · 재생목록 · 화면 · 가사 화면
  js/engine.js      Web Audio 그래프 (덱 2개 → 효과 체인 → 볼륨)
  js/effects.js     음장 효과 40종 정의
  js/fx-worklet.js  AudioWorklet DSP (직접 구현)
  js/presets.js     EQ 프리셋 18종 · 음장 프리셋 18종
  js/tags.js        태그 · 길이 · 앨범아트 · 파일 속 가사 (ID3v1/v2, FLAC, Ogg/Opus, MP4, WAV, EUC-KR)
  js/lyrics.js      가사 찾기(LRCLIB) · LRC 해석 · 공용 가사 목록 · 의견 보내기
  js/platform.js    Electron / Android / 브라우저 연결층
desktop/            윈도우용 Electron 셸 (main.js, preload.js)
android/            안드로이드 WebView 셸 (Java, AndroidX 없음)
lyrics/             공용 가사 목록 overrides.json (봇이 갱신)
.github/            가사 의견 봇(workflows/lyrics-feedback.yml, scripts/lyrics_feedback.py), 이슈 양식
build/              빌드 스크립트
test/               DSP · 화면 · 태그 · 가사 · 봇 시험
```

APK 서명 키(`android/keystore/`)는 저장소에 올리지 않습니다. 업데이트 APK 는 반드시 같은 키로 서명해야 덮어쓰기 설치되므로 따로 안전하게 보관하세요.
